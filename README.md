## Лабораторийн зорилго

Хичээлд бүртгүүлэх REST API дээр тест дизайны таван алхмыг

## Тестлэх функц

- Метод: POST
- Endpoint: /registrations
- Серверийн хаяг: http://localhost:3000
- Postman collection variable: baseUrl

## Тестийн спецификаци

| ID | Тестийн нөхцөл | Хүлээгдэх HTTP статус | Хүлээгдэх result |
|---|---|---|---|
| TC01 | Идэвхтэй оюутан, хичээл байгаа, урьдач бүрэн | 201 | OK |
| TC02 | Оюутан байхгүй, хичээл байгаа | 200 | ERROR_NO_STUDENT |
| TC03 | Оюутан идэвхгүй, хичээл байгаа | 200 | ERROR_INACTIVE_STUDENT |
| TC04 | Оюутан идэвхтэй, хичээл байхгүй | 200 | ERROR_NO_COURSE |
| TC05 | Оюутан идэвхтэй, урьдач хичээл огт үзээгүй | 200 | ERROR_PREREQUISITES |
| TC06 | Оюутан болон хичээл хоёулаа байхгүй | 200 | ERROR_NO_STUDENT |
| TC07 | Оюутан идэвхгүй, хичээл байхгүй | 200 | ERROR_INACTIVE_STUDENT |
| TC08 | Үзсэн хичээлгүй идэвхтэй оюутан, урьдачгүй хичээл | 201 | OK |
| TC09 | courseID талбар дутуу | 400 | ERROR_BAD_REQUEST |
| TC10 | Хоёр урьдач хичээлээс нэгийг үзсэн | 200 | ERROR_PREREQUISITES |

TC05-д missing = ["CS201"], TC10-д missing = ["CS202"] гэж хүлээнэ.

TC06 болон TC07 нь давхар алдааны хослолыг шалгана.
TC08 болон TC09 нь хязгаарын тохиолдлуудыг шалгана.
Байхгүй оюутанд үзсэн хичээлийн утга оноох боломжгүй тул
энэ сонголтыг тухайн тестэд хамаарахгүй гэж үзнэ.

## Newman ажиллуулалтын үр дүн

Collection нь 10 тестийн тохиолдол, setup-тайгаа нийт 25 хүсэлт,
23 assertion буюу автомат шалгалттай.

| Ажиллуулалт | Requests executed | Requests failed | Assertions executed | Assertions failed | Exit code |
|---|---:|---:|---:|---:|---:|
| PASS | 25 | 0 | 23 | 0 | 0 |
| FAIL | 25 | 0 | 23 | 1 | 1 |
| DOWN | 25 | 25 | 23 | 23 | 1 |

Бүтэн гаралтын файлууд:

- results/newman-pass.txt
- results/newman-fail.txt
- results/newman-down.txt

### PASS

Үндсэн lab05-collection.json файлыг сервер ажиллаж байх үед
ажиллуулахад бүх 23 assertion амжилттай болж, exit code 0 гарсан.

### FAIL

Тусдаа lab05-collection-fail.json файлын TC01 тестэд HTTP статусыг
зориуд 200 гэж хүлээсэн. Сервер 201 буцаасан тул нэг assertion
унаж, exit code 1 гарсан. Үндсэн collection зөв хэвээр үлдсэн.

### DOWN

Серверийг Ctrl+C дарж унтраагаад үндсэн collection-ийг ажиллуулахад
connect ECONNREFUSED 127.0.0.1:3000 алдаа гарч, exit code 1 болсон.
Хариу ирээгүй тул хариуг шалгах assertion-ууд мөн унасан.

FAIL нь серверийн хариуг oracle-ийн буруу хүлээлттэй харьцуулсан
алдаа, харин DOWN нь сервертэй холбогдож чадаагүй интерфейсийн алдаа юм.

## Дүгнэлт

Энэ лабораторид тест дизайны таван алхмыг POST /registrations функц дээр хэрэгжүүлсэн.
Эхлээд бие даан тестлэх функцийг тодорхойлж, оролтын сонголтуудыг эквивалент ангид хуваасан.
Дараа нь төлөөлөх утгууд сонгож, хүлээгдэх үр дүнтэй арван спецификаци боловсруулсан.
Сонголтуудын хослол болон давхар алдааны хүлээгдэх үр дүнг тодорхойлох нь хамгийн их бодол шаардсан.
Байхгүй оюутанд үзсэн хичээлийн мэдээлэл оноох боломжгүй тул тухайн сонголт хамаарахгүй байсан.
Шаардлагатай өгөгдлийг тест бүр өөрийн PUT setup хүсэлтээр бэлдэж, бусад тестээс хамаарахгүй болгосон.
Давхар алдааны тестүүдээр сервер оюутны байдал шалгасны дараа хичээл байгаа эсэхийг шалгадгийг баталсан.
Сонгосон арван тохиолдлын хүрээнд API-ийн хүлээгдэх зан төлөвөөс зөрсөн согог илрээгүй.
Newman ажиллуулахад export файл дахь baseUrl хоосон байсан тохиргооны алдааг илрүүлж зассан.
PASS, FAIL, DOWN туршилтуудаар амжилттай шалгалт, oracle-ийн алдаа, холболтын алдааны ялгааг ойлгосон.

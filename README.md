## Лабораторийн зорилго

Хичээлд бүртгүүлэх REST API дээр тест дизайны таван алхмыг
хэрэгжүүлж, Postman-аар бие даасан тестүүд үүсгэн,
Newman-аар автоматаар ажиллуулж үр дүнг шалгах.

## Тестлэх функц

- Метод: POST
- Endpoint: /registrations
- Серверийн хаяг: http://localhost:3000
- Postman collection variable: baseUrl

| Урьдач хичээлүүдийг үзсэн эсэх | Огт үзээгүй | Шаардлага ["CS201"], үзсэн [] |

## Тестийн спецификаци

| ID | Тестийн нөхцөл | Хүлээгдэх HTTP статус | Хүлээгдэх result |
|---|---|---|---|
| TC01 | Идэвхтэй оюутан, хичээл байгаа, урьдач бүрэн | 201 | OK |
| TC02 | Оюутан байхгүй, хичээл байгаа | 200 | ERROR_NO_STUDENT |
| TC03 | Оюутан идэвхгүй, хичээл байгаа | 200 | ERROR_INACTIVE_STUDENT |
| TC04 | Оюутан идэвхтэй, хичээл байхгүй | 200 | ERROR_NO_COURSE |
| TC05 | Оюутан идэвхтэй, урьдач хичээл огт үзээгүй | 200 | ERROR_PREREQUISITES |
| TC06 | Оюутан болон хичээл хоёулаа байхгүй | 200 | ERROR_NO_STUDENT |
| TC07 | Оюутан идэвхгүй, хичээл байхгүй | 200 | ERROR_INACTIVE_STUDENT |
| TC08 | Үзсэн хичээлгүй идэвхтэй оюутан, урьдачгүй хичээл | 201 | OK |
| TC09 | courseID талбар дутуу | 400 | ERROR_BAD_REQUEST |
| TC10 | Хоёр урьдач хичээлээс нэгийг үзсэн | 200 | ERROR_PREREQUISITES |

TC05-д missing = ["CS201"], TC10-д missing = ["CS202"] гэж хүлээнэ.

TC06 болон TC07 нь давхар алдааны хослолыг шалгана.
TC08 болон TC09 нь хязгаарын тохиолдлуудыг шалгана.
Байхгүй оюутанд үзсэн хичээлийн утга оноох боломжгүй тул
энэ сонголтыг тухайн тестэд хамаарахгүй гэж үзнэ.
